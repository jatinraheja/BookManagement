# Intelligent Book Manager API

This project is a FastAPI-based backend application that manages a library of books and reviews. It leverages Artificial Intelligence (AI) to generate book summaries and provide personalized book recommendations.

## Technologies & Libraries

### Core Framework
*   **FastAPI**: Used for building the high-performance API.
*   **Uvicorn**: An ASGI web server implementation for Python.

### Database Connectivity
*   **SQLAlchemy**: The Python SQL toolkit and Object Relational Mapper (ORM) used to interact with the database.
*   **PostgreSQL**: The relational database management system storing books and reviews (connected via `psycopg2` or similar driver).

### AI & LLM Integration
*   **LangChain**: A framework for developing applications powered by language models.
*   **OpenAI**: The specific LLM provider used (via `langchain-openai`) for text summarization and generating recommendations.

---

## API Endpoints

### Book Management

#### 1. Add a New Book
*   **Method**: `POST`
*   **Endpoint**: `/books/`
*   **Description**: Creates a new book entry. The system automatically utilizes AI to generate a summary based on the provided title and author if no specific summary is given.
*   **Body**: JSON object containing `title`, `author`, `genre`, etc.

#### 2. Retrieve All Books
*   **Method**: `GET`
*   **Endpoint**: `/books/`
*   **Description**: Returns a list of all books in the database. Supports pagination via query parameters (`skip`, `limit`).

#### 3. Retrieve a Specific Book
*   **Method**: `GET`
*   **Endpoint**: `/books/{book_id}`
*   **Description**: Fetches detailed information for a single book defined by its ID.

#### 4. Update a Book
*   **Method**: `PUT`
*   **Endpoint**: `/books/{book_id}`
*   **Description**: Updates specific fields of an existing book. Only the fields provided in the payload will be updated.

#### 5. Delete a Book
*   **Method**: `DELETE`
*   **Endpoint**: `/books/{book_id}`
*   **Description**: Removes a book and its associated data from the database.

---

### Reviews & Ratings

#### 6. Add a Review
*   **Method**: `POST`
*   **Endpoint**: `/books/{book_id}/reviews`
*   **Description**: Adds a user review and rating to a specific book.

#### 7. Retrieve All Reviews
*   **Method**: `GET`
*   **Endpoint**: `/books/{book_id}/reviews`
*   **Description**: Fetches a list of all reviews associated with a specific book.

#### 8. Get Book Summary & Stats
*   **Method**: `GET`
*   **Endpoint**: `/books/{book_id}/summary`
*   **Description**: Returns a composite object containing the book's AI-generated summary, its calculated average rating, and the total count of reviews.

---

### AI Features

#### 9. Get Recommendations
*   **Method**: `GET`
*   **Endpoint**: `/recommendations`
*   **Description**: Accepts user preferences (e.g., "I like sci-fi with time travel") and returns a list of recommended books generated by the LLM.
*   **Query Parameter**: `preferences` (string)

#### 10. Generate Summary from Content
*   **Method**: `POST`
*   **Endpoint**: `/generate-summary`
*   **Description**: A utility endpoint that accepts raw text content (such as a book excerpt or full text) and returns a concise AI-generated summary. This does not store data in the database.
